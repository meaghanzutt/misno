# Changelog

## 1.0.0-alpha.1
- Created React + Vite + TypeScript foundation.
- Added Tailwind design tokens and shared components.
- Added public, community, Workspace, Admin, and Style Guide routes.
- Added Netlify configuration and Identity shell.

## 1.0.0-alpha.2 - Design System Foundation

### Added
- New `/design-system` route with foundations, components, forms, interaction patterns, and layout previews.
- Reusable `Avatar`, `Badge`, `FormField`, `Modal`, `Tabs`, `ProfileCard`, `EmptyState`, and mobile navigation components.
- Button sizes, loading state, icon variant, and destructive state.
- Responsive public navigation and Community bottom navigation.
- Reduced-motion support and expanded shared CSS design tokens.

### Changed
- `/styleguide` now redirects to `/design-system`.
- Community search now uses the shared search component.
